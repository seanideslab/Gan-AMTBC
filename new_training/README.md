## What is implemented

- Deterministic AMBTC encode/reconstruct for 4×4 blocks; independent, reversible bitmap payload insertion with exact image-level bit budget (`ambtc.py`). This **new embedding protocol** uses 0–8 bits/block and a seeded unique position permutation. It is not the original STC/Double-Tanh implementation and has not been tested for steganalytic security.
- New one-channel, bitmap-preserving quantization compensation candidate using an Attention ResUNet with 50/100/200/400 channels (`models.py`). The shape fingerprints from the recovered summary match nine entries; this does **not** establish that it was the paper's model. The network predicts a residual map projected to per-block H/L corrections; bitmap is unchanged, preserving extraction.
- Dataset manifest with image SHA-256 and new train/val/test split. A manifest generated today is **NOT** the missing paper split. Default 256 px is a staged training size; use `--size 512` for a new experiment at the published resolution. The publication's 512px split and five seeds remain unrecovered.
- Genuine gradient-based, checkpoint-saving **distortion-only** generator training (`train_generator.py`). The target is the AMBTC-reconstructed cover; no SRM/SRNet or adversarial loss is claimed.
- Separate constrained, contextual PPO **quality-and-budget-only** training (`train_policy.py`). The recovered 256×256 actor/critic architecture is used with known parameters; the original DQN reward scheduler and security signals are not recovered or trained.
- Holdout evaluation of this new model (`evaluate_new.py`) with actual payload extraction, bit error count, PSNR vs raw and vs AMBTC cover; **no P_E** in the absence of a properly trained detector.

## Prerequisites

Python ≥3.10, `torch`, `Pillow`, `numpy`; GPU recommended for 50-channel training at 256/512. Install PyTorch from its official channel appropriate to your CUDA driver. Do not copy bundled image datasets from the Internet without checking rights.
